#  SmartShop – Modern E-Commerce Web App

SmartShop is a fully responsive and interactive e-commerce web application built using **HTML, Tailwind CSS, and JavaScript**.  
It demonstrates real-world frontend development concepts like API integration, cart system, dark mode, filtering, and local storage.

---

##  Live Features

###  Product System
- Fetch products dynamically from FakeStore API
- Display product cards with image, price, rating, and category
- Search products by name
- Filter products by category
- Sort products (low-high price, high-low price, rating)

###  Shopping Cart
- Add / remove products from cart
- Increase / decrease quantity
- Real-time cart total calculation
- Cart sidebar UI
- Auto update cart badge count

###  Balance System
- User starts with initial balance (1000 BDT)
- Add more money anytime
- Checkout deducts balance automatically
- Balance stored in localStorage

###  Coupon System
- Apply coupon code: `SMART10`
- Get 10% discount on subtotal

###  Dark Mode
- Toggle light/dark mode
- Preference saved using localStorage
- Persistent across reload

###  UI Components
- Hero banner slider (auto + manual control)
- Review carousel slider
- FAQ accordion system
- Toast notifications

### 📩 Contact Form
- Form validation (name, email, message)
- Success & error messages

##  How It Works

1. Products are fetched from API on page load
2. User can browse, search, and filter products
3. Items can be added to cart
4. Cart calculates total price in real-time
5. Checkout deducts balance
6. Data (balance & dark mode) is saved in browser

---

##  Key Features (Behind the Scenes)

- Array methods: `map`, `filter`, `reduce`, `find`
- DOM manipulation for dynamic UI
- Event handling system
- State management using variables
- LocalStorage persistence
- Responsive design with Tailwind CSS
